# Bharat Technology Capability Centre (BTCC)

**From Knowledge to National Capability**

BTCC is an autonomous institution dedicated to bridging the gap between scientific research and sovereign operational capability for India's 2047 national milestones.

## Website Architecture

### Core Pages
- `index.html`: Main portal homepage (Hero, 6 Pillars Strip, The BTCC Idea preview, Capability Chain preview, 2047 Horizon banner, 8 Frontier Technologies, Capability Missions, Strategic Imperatives)
- `idea.html`: The BTCC Idea (Strategic rationale, 8 central inquiries, 5-stage translation chain, What BTCC Is vs. Is Not, BTCC Formula)
- `capability.html`: Capability Architecture (5 Institutional Pillars, 7-Stage Operating Cycle, Capability Assessment Pathway)
- `missions.html`: Capability Missions (Deep dive into Autonomous Systems, Resilient Cyber Physical Systems, and Dual-Use Technology Translation)
- `knowledge.html`: Knowledge Infrastructure (6 Flagship Knowledge Assets, 4 Publication Categories)
- `ecosystem.html`: The Capability Ecosystem (6 Ecosystem Dimensions, BTCC Fellows & Expert Network across 6 categories)
- `engage.html`: Engagement & Collaboration Gateways (5 Institutional Pathways, Institutional Collaboration Enquiry Portal)

### Modular Stylesheets
- `common.css`: Site-wide shared styling including design tokens, typography, clean white header, responsive drawer, master footer, buttons, and utility classes.
- `home.css`: Dedicated styling for the homepage (`index.html`).
- `idea.css`: Dedicated styling for The BTCC Idea page (`idea.html`).
- `capability.css`: Dedicated styling for the Capability page (`capability.html`).
- `missions.css`: Dedicated styling for Capability Missions page (`missions.html`).
- `knowledge.css`: Dedicated styling for the Knowledge page (`knowledge.html`).
- `ecosystem.css`: Dedicated styling for the Ecosystem page (`ecosystem.html`).
- `engage.css`: Dedicated styling for the Engage page (`engage.html`).
- `styles.css`: Backward-compatible master entrypoint.

### Script & Assets
- `script.js`: Clean navigation, sticky header transitions, mobile drawer handling, search modal, and smooth scrolling.
- `assets/`: Frontier technology imagery, mission visuals, and institutional banners.
